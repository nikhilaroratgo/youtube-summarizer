# YouTube Video Summarizer

Paste a YouTube link, get a summary. Uses YouTube's built-in captions when available, falls back to Whisper audio transcription. Summaries are generated by Claude and viewable in a local web UI.

## Setup

Install [uv](https://docs.astral.sh/uv/) if you don't have it:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Install dependencies and set your API key:

```bash
cd youtube_summarizer
uv sync
```

Create a `.env` file in the project root:

```
ANTHROPIC_API_KEY=your_key_here
```

> **Note:** ffmpeg is required only for the Whisper fallback. Install with `brew install ffmpeg` (macOS) or `sudo apt install ffmpeg` (Ubuntu).

## Usage

```bash
uv run main.py "https://youtube.com/watch?v=VIDEO_ID"
```

### Options

| Flag | Description |
|------|-------------|
| `--style detailed` | Full structured summary with key points and takeaways (default) |
| `--style brief` | 3–5 sentence overview |
| `--style bullets` | Key points as a bulleted list |
| `--whisper` | Skip YouTube captions, force audio download + Whisper transcription |
| `--save-transcript` | Also save the transcript to `output/` |
| `--transcript-only` | Extract transcript only, skip summarization |

### Examples

```bash
# Default detailed summary
uv run main.py "https://youtu.be/dQw4w9WgXcQ"

# Quick bullet-point summary
uv run main.py "https://youtu.be/dQw4w9WgXcQ" --style bullets

# Force Whisper and save transcript
uv run main.py "https://youtu.be/dQw4w9WgXcQ" --whisper --save-transcript

# Just get the transcript text
uv run main.py "https://youtu.be/dQw4w9WgXcQ" --transcript-only
```

Summaries are automatically saved to the `output/` folder after each run.

## Web UI

View all your summaries in a local web interface:

```bash
node server.js
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.

- **Home page** — card grid of all summaries with YouTube thumbnails
- **Detail page** — fully rendered summary with headings, tables, and bullet points
- **Live** — picks up new summaries automatically, no restart needed

> Requires Node.js. No npm install needed — zero dependencies.

## How It Works

```
YouTube URL
    │
    ▼
Extract video ID
    │
    ├─── Try YouTube captions (fast, no download)
    │         └── success → transcript text
    │
    └─── Fallback: download audio via yt-dlp
              └── transcribe with Whisper → transcript text
                        │
                        ▼
              Send to Claude API → summary
                        │
                        ▼
              Saved to output/ → viewable in web UI
```

**Transcript methods:**
- **YouTube captions** — pulls directly from YouTube's subtitle API. Works for most videos. No audio download needed.
- **Whisper** — downloads audio via yt-dlp, runs OpenAI Whisper locally. Slower but works for any video.

## Code Formatting

This project uses [Black](https://black.readthedocs.io/en/stable/), an opinionated Python code formatter that enforces a consistent style automatically.

Black is included as a dev dependency and installed with `uv sync`. To format all Python files in the project at once:

```bash
uv run black .
```

This recursively formats every `.py` file under the current directory. To target specific files instead:

```bash
uv run black main.py summarizer.py transcriber.py
```

To preview changes without applying them (works with both forms):

```bash
uv run black . --diff
```

Black uses a default line length of **88 characters** and requires no configuration.
